# Pizza Site

A personal reference project — a warm, handcrafted-style pizza restaurant website built while I document ideas, recipes, and layout concepts from my time working at a pizza shop. Long-term goal: use this as a foundation and knowledge base if I open my own pizza shop in Uzbekistan.

**Live site:** https://phlorenci.github.io/pizza-site/

## Tech stack
- Vite + TypeScript
- Plain HTML/CSS (no framework)
- Deployed via GitHub Pages

## Status
Design and layout are in place with placeholder content for menu items, pricing, and restaurant details. Real content (recipes, pricing, final copy) is being filled in gradually — see `notes.md` for ongoing ideas (kept local/private, not committed).

## Structure
- `src/components/` — reusable UI pieces (nav, menu cards, process steps, contact form)
- `src/data/placeholderData.ts` — menu items and process steps (currently placeholder data + a few real photos)
- `public/images/pizzas/` — pizza photos
